# Doughnut Workspace

A local Windows app where you and your AI agents share work: projects, boards of cards, pages, and agent terminals side by side. Free first: everything it does can be done for free.

This repository holds the **releases**: the Windows installer and the official add-ons. The app's code is not public yet.

## Getting it
Download the installer from [Releases](../../releases). It is not signed yet, so Windows may say "Windows protected your PC": choose More info, then Run anyway.

## Official add-ons
Add-ons are installed from inside the app (Settings > Add-ons > Get add-ons), not by hand. Each one is a release here tagged `addon-<name>-v<version>`. The app carries the fingerprint (SHA-256) of every official add-on and throws away any download that does not match, then asks you before anything runs.

- **Voice**: talk to agents, hear their replies, transcribe sound and video. Free and offline.
